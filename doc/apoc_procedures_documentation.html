APOC Procedures Documentation

deposit.create.database

Creates a new database and adds a Metadata node with specified properties. @param databaseName the name of the database to create. @throws RuntimeException if the database name ends with '_archive' or if there is an error during creation.

Parameters:

  • databaseName: the name of the database to create.

Throws:

  • RuntimeException: if the database name ends with '_archive' or if there is an error during creation.

Usage:

CALL deposit.create.database(parameters)
